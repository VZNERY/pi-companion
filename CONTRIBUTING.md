1. Your contribution may be included in this project under its license (PolyForm Noncommercial 1.0.0).
2. You grant the project maintainer the right to use, modify, and relicense your contribution as part of this project.
3. You have the right to make the contribution, and it does not include code you are not allowed to share.

Before opening a pull request, run `npm test` and make sure all tests pass.
